# HOISA 記事タグの決まり (2026-11-01)

HOISA は長野県飯田市・下伊那郡の地域情報ブログ (書き手: 紗代さん / FUNE)。
タグは「記事の最後のタグ」「/blog の絞り込み」「人気のタグ」「関連記事の自動選定 (共通タグが多い記事を優先)」に使われる。
**タグ = 読者が『同じ種類の記事をもっと読みたい』ときの入口**。一度しか使わない細かいタグは作らない。

## 1. 地域タグ (必須)

- 飯田市の記事: `飯田市` を必ず付ける。地区がはっきり分かれば地区タグも付ける (下の一覧の名前だけ使う)。
- 下伊那郡の町村の記事: `下伊那郡` と町村タグ (例 `下伊那郡・豊丘村`) の両方。
- 地区・町村の判断は **タイトルの【】や本文に明記されているもの** を根拠にする。推測で付けない。
  タイトルの【】と本文が食い違うときは本文の実際の場所を優先 (例: 豊丘村の話なのに喬木村タグ → 豊丘村)。
- 飯田市の外の町村の店が飯田市内で買える等の記事は、記事の舞台 (飯田市) を地域タグにする。

## 2. 内容タグ (2〜4 個、この一覧からだけ選ぶ)

## 4. 数の目安

地域 1〜2 + 内容 2〜4 + 固有名 0〜2。合計で多くても 7 個。迷ったら付けない (少なく正確に)。

## 5. 付け方の順番 (表示のため)

記事一覧のカードにはタグが**最初の 3 つ**しか出ない。地域タグを先に付けるとカードが地域ばかりになるので、
**内容タグ → 固有名タグ → 地区・町村 → 市・郡** の順に付ける (post_hashtags の挿入順がそのまま表示順になる)。
